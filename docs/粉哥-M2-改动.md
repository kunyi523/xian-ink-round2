## 改动摘要

### 印鉴底栏
- Tab 标签：拜山 / 开光 / 仙山 / 云游 / 道藏（印文：缘/识/山/游/道）
- 选中 = 朱砂填印；教程拜山 / 云游可领时用 `.nav-pulse`（不再 `animate-pulse`）

### 对照卷 Sheet
- `max-h-[38vh]` → `max-h-[48vh]`；卷首「轴头」+ 卷名（拜山卷/开光卷/山门对照…）
- 仙山面板按 **山麓→山腰→近劫** 分组；文案标明「主购在山体碑亭」
- 未解锁提示：`机缘未至`

### HUD / 词表（壳层展示，键名仍 qi/dps/jade）
- 灵气大字旁标 **香火**；DPS → **山息/秒**
- 玉→仙玉（展开态）；连击→开光；面板标题与教程对齐大纲词表

### WorldCanvas
- 仅劫核 / 仙果 / 碑亭响应点按；空白只平移
- 拖动阈值 12px；碑亭热区按 `max(hw,hh)*0.48`（最小 32）
- `hall` hw/hh → 0.14/0.16（@0.48,0.70）；`house`/`tower` 略放大，**nx/ny 不变**

### 稀有度
- UI 用壳层墨阶数组；境界名作小方印（`.rarity-stamp`），不用彩虹 `RARITY_COLOR`
