> 给 Kunyi 看的总蓝图。`游戏核心/` 为权威；`源码/src/game/` 必须镜像。

---

## 0. 一句话愿景

**不是「点一下产灵气的挂机店」，而是：你在一座残破空峰上，用指尖开光、用香火立门，把废墟一点点写成水墨仙山。**

玩家幻想主轴：**从 0 到 1 的开山立派**——先点亮第一炷香，再来弟子、再开脉、再接天，最后渡劫飞升留下道种。

## 2. 反抄袭清单（Anti-Clone Checklist）

### 2.1 必须抹掉的「他游味道」

| 味道来源 | 当前痕迹 | 重建方向 |
|---|---|---|
| Cookie Clicker | 点击产币 + 建筑 DPS 列表 + 自动点击器 | 改为「开光 / 香火 / 山息」；建筑是山势节点非商店货架 |
| Realm Grinder | 转生收果、多层加成乘区堆叠文案 | 渡劫保留「道果」但叙事改成「劫后余烬种回空峰」；少用「永久 ×%」堆字 |
| 国产修仙挂机 | 仙缘抽卡、秘境挂机、宗门大殿/外门院套词 | 抽卡→**拜山投缘**；秘境→**云游闭关**；建筑全面改名改味 |
| 通用 idle | Tab「神识/宗门/秘境」、任务「造成 X 伤害」、存档键 `xian-clicker` | 改隐喻与文案；存档键可在 P2 迁到 `xian-tu-v2` |
| 抽卡游戏 | pity、十连九折、稀有度彩虹字 | 保留数值，包装成「香火簿 / 缘分」；稀有色走水墨朱金（TOP5 已起步） |

### 2.2 过关标准（验收）

- [ ] 截图发给没玩过的人：第一反应是「水墨仙山」而非「又一个点点点」
- [ ] 建筑面板不像商店：有山势分区（山麓 / 山腰 / 近劫），不是纯价签列表
- [ ] 全程文案无「伤害/秒」「发电机」「自动点击」；用「山息」「开光」「香火」
- [ ] 开局 3 分钟能感到「空峰变有烟火」，而不只是数字涨
- [ ] 粉哥侧：印章/显形/音效与 Micheal 数值叙事同一套词表

详细字符串对照见：`他游痕迹扫描.md`。

## 3. 新核心循环（Early → Mid → Late）

### 3.1 循环一句话

**开光劫云 → 攒香火（灵气）→ 在空峰落下第一枚印记 → 弟子拜山 → 龙脉自转 → 云游补玉 → 渡劫留种 → 重回空峰。**

### 3.2 阶段目标

| 阶段 | 时长感 | 玩家在干什么 | 山长什么样 | 关键解锁 |
|---|---|---|---|---|
| **序·空峰** | 0–2 分钟 | 只点劫云；教程教「开光」 | 残山 JPG；无建筑烟火 | 教程 4 步改写 |
| **早·立门** | 到建起香案+云阶 | 买第一座印记；第一次拜山 | 山麓有灯火/香烟 | `hall`→`house`；仙玉首抽 |
| **中·开脉** | 剑冢→残纹→脉口 | 挂机开始有存在感；开第二云游槽 | 山腰剑光/阵纹亮起 | `sword`→`array`→`mine` |
| **晚·接天** | 雷骨塔→望劫镜→丹烟灶 | 点击线与挂机线并重；炼器开 | 近峰有雷纹与镜光 | `tower`→`mirror`→`alchemy` |
| **劫·留种** | 总伤够渡劫 | 重置建筑，保留人/功法/部分玉 | 山再残，但香火种还在 | 渡劫 + 道种起步 |

### 3.3 与旧循环对照

| 旧 | 新（同机制，换幻想） |
|---|---|
| 点层掉血 / DPS | 开光劫云 / **山息**（每秒化气） |
| 买建筑 | **落印 / 开光山势** |
| 自动点击（无为） | **山中无为 · 香火自燃** |
| 抽卡弟子 | **拜山投缘** |
| 秘境探索 | **云游闭关** |
| 渡劫 prestige | **劫后归山**（空峰重写，道种留底） |

数值骨架（costScale / baseDps / 渡劫公式）P0 **不改**；先换名与空间，再在 P1 调节奏墙（矿洞/丹阁解锁墙、首渡后干点）。

### 5.1 三资源隐喻

| 资源 | 旧感觉 | 新隐喻 | 主要来源 |
|---|---|---|

| 草/矿 | craft mats | **灵草 / 脉晶** | 丹灶、龙脉口挂机 |
| 道果 | prestige 币 | **劫余道果** | 渡劫、层内填劫 |

### 5.2 早中晚节奏目标（P1 调数）

1. **早**：裸开光可破 0–2 层；香案 15 香火可及；2 分钟内落第一印。
2. **中**：云阶点亮后「香火自燃」有可见飘字（TOP1 已修）；剑冢前有一小段期待，不要三座墙叠一起。
3. **晚**：丹灶前解锁墙 → 改为「脉口≥1 **或** 层数≥N」双条件之一（P1）；炼器不要首周目末才摸到。
4. **渡劫**：首渡后若无金丹御剑，用道种+香案免费残影（或送一次拜山）避免二周目纯干点（P1）。

### 5.3 乘区叙事（避免 RG 味）

对外少写「全宗 +x%」堆叠；面板用：

- 香火（香案）· 剑鸣（悬剑）· 阵眼（残纹）· 山息（功法）  
内部公式可暂留，文案先换。
