## 改动摘要

### audio.ts
- 去掉 `square` / `sawtooth` 主音色。
- 原语：`tone`（sine/triangle）、`burst`（滤波噪声）、`bell`（磬/钟）、`pluck`（拨弦）。
- 分层：
  - `click`：木鱼噪头 + 低频正弦；`crit` 叠清越泛音
  - `upgrade`：G–D–G 上行五度拨弦
  - `layer`：低钟 + 余韵 + 低频噪
  - `prestige`：更长钟磬 + 风噪空间感
  - `gacha`：印泥噪 + 拨弦；rarity≥3/5 加磬
  - `orb`：短琴泛音
- **无采样包体**：本里程碑用合成近似；`public/sfx/` 采样可并行后换肤，API 不必改。

### WorldCanvas
- `juice.on` 增加 `mission` 分支（独立于 upgrade 爆发）。
- `pulseVibrate(ms)`：仅 `shakeOn` 时调用 `navigator.vibrate`。
- 建筑 DPS 投射物：非朱砂色压向墨灰；不再用硬圆 `spark` 作主反馈。
- 残留 `spark`/`dot` 绘制改为软边椭圆墨晕。

### store
- `claimMission`：保留 `juice.emit({t:"mission"})` + upgrade 兜底；新增 `if (s.sfxOn) sfx.orb()`。
- `setSfx` → `setSfxEnabled` 原有接线未改；`layer` 调用前仍检查 `sfxOn`。

## 验收建议

1. 开音效：点劫核听木鱼感；暴击多一声清越泛音（非方波哔哔）
2. 升级听拨弦上行；破层听低钟；渡劫余韵更长
3. 关音效：破层/升级均无声（含 `layer`）
4. 领任务：屏幕淡闪 +「事毕」+ 软墨点；有震动设备且震屏开时短振
5. 关震屏：无 vibrate；开震屏：暴击/破层有短振
