## 2. 视觉方向（落地到 token / 布局）

### 2.1 色板（在现有 `@theme` 上收敛，不另开霓虹）

| Token | 用途 | 建议值（可微调） |
|---|---|---|
| `--color-paper` / `paper-2` | 卷面底 | `#f3eee4` / `#e8e0d2`（保持） |
| `--color-ink` → `wash` → `faint` | 正文→注释→弱信息 | `#1c1914` / `#7a7468` / `#9a9488` |
| `--color-seal` / `seal-dim` | 印鉴、主 CTA、暴击点缀 | `#a63d32` / `#6e2a24` |
| 远山青灰（新增建议） | 远峰轮廓、未解锁碑 | `#6a7168` 或 paper 混 `ink` 28% |
| 禁色 | 彩虹 rarity、纯金 `#ffd700`、赛博青 | — |

### 2.2 字体层级

- **匾额/标题**：`font-display`（Noto Serif SC），字距略松 `tracking-widest`
- **正文/按钮**：`font-sans`，字重 600 仅 CTA
- **数字**：`font-mono` 只给资源与价格，避免整页等宽感
- 面板内：**印题一行 + 正文两行上限**，禁止墙式描述（长文留给 Micheal 的 `flavorKey` 展开）

### 2.3 建筑：从「图标货架」→「山体落位碑/亭」

- 保留 `ink.ts` 的 `BUILDING_SLOTS`（`nx/ny/band/z/hw/hh`）为权威落位；Round-2 **由 Micheal 重排坐标**，粉哥只消费。
- 视觉原则：
  1. **未解锁**：淡墨碑影 + 青灰远山剪影，不可点或点出「机缘未至」
  2. **已建 Lv0→1**：碑→亭递进（tier 0–3 已有 `buildingTier`，贴水墨描边而非图标框）
  3. **选中/可购**：碑侧浮出短签（一名 + 价），不弹整页货架
  4. **Band 分区**：`band0` 远峰、`band1` 山腰、`band2` 山脚；滑动仙山时分区标题淡入（「外门」「山腰」「云巅」）
- 列表 Sheet 仅作**对照卷**（快捷升级），主操作在山。

### 2.4 稀有度（壳层实现约定）

```
稀有度视觉 = 墨浓度(0.25→0.95) + 印形(方/圆/随形) + 是否朱砂填朱
禁止 = HSL 彩虹、星级条、光效描边彩虹
```

`RARITY_COLOR` 改为墨阶数组或壳层自算；Micheal 只需保证 `rarity: 0..7` 稳定。

## 4. 音画升级

### 4.1 音频（`audio.ts`）

- **方向**：方波 beep → **短采样优先**（古筝拨弦 / 木鱼 / 钟磬 80–220ms），无采样时用 FM/噪声+正弦做「木感」近似，禁止锯齿电音主音色。
- 分层约定：
  - `click`：轻木鱼或短拨弦；`crit` 叠一声清越泛音
  - `upgrade`：三音递进改成上行五度拨弦，勿 square 爬梯
  - `layer`（破层）：低钟 + 余韵；**必须尊重 `sfxOn` / `setSfxEnabled` 接线**
  - `prestige`（渡劫）：钟磬长余韵 + 风噪淡入，与破层区分「更大空间感」
  - `gacha`：按 rarity 加印泥落印声，高稀有多一声磬
- 包体：采样放 `public/sfx/`，单文件 ≤30KB，优先 mono 22kHz。

### 4.2 粒子 / juice

- 用水墨晕染：低饱和墨点、边缘软、寿命略长；砍掉高频 `spark` 作为主反馈。
- 补齐痛点：处理 `mission` juice（短闪光+飘字「事毕」）；auto 点击减粒子密度、降音量（玩法侧 Micheal 若改 `click(auto)` 则壳层配合）。
