## 0. 本轮目标

把「从 0 到 1 开山」的体感做顺：序章能点出第一炷香，中期不撞三座硬墙，首渡归山不纯干点。  
数值骨架（baseCost / baseDps / costScale / 渡劫公式）**原则上不动**；只动解锁条件、离线礼、首渡赠礼、文案与极少数节奏常数。

## 4. 已落地代码（本轮）

同步文件：`游戏核心/{store,sim,data}.ts` ↔ `源码/src/game/`。

1. **`sim.buildingUnlocked`**：丹灶软解锁（脉口≥1 或 layer≥8，或前座望劫≥1）。
2. **`store.tick`**：第二云游槽 `house >= 3`。
3. **`store.hydrate`**：离线礼系数 `0.5`。
4. **`store.prestige`**：归山赠 `hall=1`；`jade = max(keepJade, 10)`。
5. **`store` toasts**：云游归来 / 劫后归山 / 事成·缘玉；仙果文案「香火」。
6. **`data` array.perk**：与自乘公式对齐。

## 6. 验收（Micheal）

1. 新档：香案仍 15；旧档 buildings 等级可读。  
2. 有脉口或层≥8 时，未建望劫镜也能在仙山/对照卷看到丹灶（买不起仍锁价）。
