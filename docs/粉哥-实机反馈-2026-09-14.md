## 1) Mountain 0→1 reveal

- **原状**：`hall` 有级则整切修好山 JPG，开局一点香案就「已仙府」。
- **改后**：`mountainReveal(buildings, layer, totalDamage)` → 0..1  
  - 0 印记 → **纯残山**  
  - 印记数为主（×0.72），香案级 / 层 / `log10(totalDamage)` 轻推  
  - 早中期仍偏废墟，满山印记才近修好
- `ensureMountainCache(blend, …)`：先画 ruin，再以量化透明度叠 mountain（`round(blend*20)/20` 进 cache key）→ **blend 变档才重建**，pan 不触发。
- `syncBlit` 用 ruin（或 fallback mountain）算 cover 尺寸；离屏已含混合。

## 2) 劫核视觉

- `tribCenter.R`：`0.092` → **`0.128`**（约 +39%；点空开光已不靠 R 命中）。
- `drawTribCloud`：径向淡墨 wash、更多墨云瓣、墨核渐变、**软朱砂印心**（非硬红椭圆）、宣纸高光一点。
- 绘制调用：`R * (1.18 + vortexPulse*0.07)`，只放大画出，**未改** orb/建筑热区与 Micheal 空白 click。

## 3) 进度小数

- HUD 任务行原 `{progress} / {target}` 对 `kind:"damage"`（开光累计）会吐长 float。
- `formatMissionProgress`：`target≥100` 时 `formatNum(floor(p)) / formatNum(floor(t))`；小数小目标可走整数 %；其余 floor 整数比。
